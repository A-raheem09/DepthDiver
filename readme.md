# Depth Diver
 Make it to the bottom of the level into Barnabus' dungeon
 little to no handholding
 Controls:
 - W/UpArrowKey/Space: JUMP
 - S/DownArrowKey/Shift: DESCEND
 - A/Left: Move Left
 - D/Right: Move Right
there are invisible platforms and bouncers that will ruin your runs
Kinda like a souls game in platformer form?
